# 📊 UPI Data Analysis Dashboard (Tableau)

## 🔍 Project Overview
This project showcases an **interactive Tableau dashboard** built to analyze **UPI (Unified Payments Interface) transaction data** across multiple dimensions such as **age group, city, payment method, merchant, bank, device type, currency, and purpose**.  
The dashboard provides actionable insights into digital payment trends and user behavior across India.

---

## 🎯 Objectives
- Analyze UPI transaction distribution across **age groups**
- Compare **city-wise transaction volumes**
- Understand usage patterns of **UPI payment methods**
- Evaluate **merchant-wise transaction performance**
- Enable **interactive filtering** for detailed analysis

---

## 🛠 Tools & Technologies
- Tableau Desktop
- Excel / CSV Dataset
- Mapbox (Geographic Visualization)

---

## 📈 Dashboard Features

### 🔹 Interactive Filters
- Bank Name Received  
- Currency  
- Device Type  
- Payment Mode  
- Purpose  

### 🔹 Key Visualizations
- Number of Transactions by Age Group  
- Total Transactions by City (Map View)  
- Total Transactions by Payment Method & Merchant Name  
- Merchant-wise comparative bar charts  

---

## 🗺️ Key Insights
- Metro cities like **Delhi, Mumbai, Hyderabad, and Bangalore** show the highest UPI transaction volumes.
- **Age Group 3** contributes the maximum number of transactions.
- **QR Code and UPI ID** are the most widely used payment methods.
- Merchants such as **Amazon, Flipkart, Swiggy, Zomato, and IRCTC** dominate transaction activity.
